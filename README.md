# Claude Holiday Course

A self-guided, 10-week course for learning Claude, Claude Code and Claude Science.

Open the site, pick a week on the trail, work through each topic and tick off tasks as you finish them. Press **Reset** on any task to do it again.

## Progress

- Progress is saved in the browser on the device you're using.
- Clearing browsing data, or using a private window, erases it.
- To move progress to another device, use **Copy my progress** at the bottom of the page, then **Paste progress from another device** on the other device.

## Publishing

This site is served by GitHub Pages from the `main` branch, root folder (`/`).
